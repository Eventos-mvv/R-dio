⚙️ Configuração necessária (só na primeira vez)

Este painel usa o Firebase Realtime Database para sincronizar entre celulares em tempo real. Cole abaixo o firebaseConfig do seu projeto (Console Firebase → Configurações do projeto → seus apps → SDK setup and configuration).

Se você já tem um projeto Firebase de outro painel (ex: SETORES), pode reaproveitar o mesmo — só use uma chave nova no banco, tipo /radios25, pra não misturar os dados.
